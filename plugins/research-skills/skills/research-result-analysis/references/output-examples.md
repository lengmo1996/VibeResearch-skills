# Result Analysis Output Examples

Shapes of a good answer, not templates. Numbers are invented for illustration.

<example>
User: 我的方法在 KITTI 上 AbsRel 0.061，基线 0.064，能说明我的尺度模块有效吗？（附两行结果表和训练日志）

Answer:
现在还不能这么说。0.003 的差距只来自各一次运行，日志里两边的随机种子不同，也没有重复
实验，所以不知道这个差距是否大于种子带来的波动。另外你的模型比基线多训了 5 个 epoch
（日志第 212 行），提升也可能来自训练更久。

能支持的写法是：“在单次运行中，加入尺度模块后 AbsRel 从 0.064 降到 0.061。”

下一步最有用的是：两边在相同 epoch 下各跑 3 个种子。如果差距仍然稳定在 0.003 左右，
且大于种子间的波动，再说模块有效。
</example>

<example>
User: 帮我看看这个消融表说明了什么。（附去掉三个模块各自的结果）

Answer:
三个模块里只有注意力融合在去掉后明显变差（AbsRel 0.061 → 0.070），另外两个的变化都在
±0.001 以内，这张表看不出它们有作用。

有一点要注意：去掉注意力融合的同时，参数量也少了 18%，所以变差可能部分来自容量下降。
要分开这两个因素，可以用一个参数量相同、但不做跨尺度注意力的替代模块再跑一次。
</example>
