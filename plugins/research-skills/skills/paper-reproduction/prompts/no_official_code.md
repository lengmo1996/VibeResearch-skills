# No Official Code Prompt

Before implementation, produce:

- interface and tensor-shape contracts;
- algorithm pseudocode;
- state and initialization assumptions;
- expected invariants and outputs;
- paper-fixed behavior versus engineering choices;
- unresolved ambiguities that could affect equivalence.

Any authorized code is a candidate implementation, never a claim of paper equivalence.
The specification can complete without write authorization. Only when requested and
authorized implementation produces changed code, add the Implementation Patch and
the report template's Verification Handoff; otherwise omit both.
