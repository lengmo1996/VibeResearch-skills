# Structure workflow quality checklist

Use this checklist when changing the structure-planning behavior.

## Trigger clarity

- [ ] “Outline the story and paragraph functions for this introduction” selects
      `writing-academic`.
- [ ] “Draft an abstract from these verified contribution and result points” selects
      `writing-academic`.
- [ ] “Reverse-outline this manuscript and diagnose structural defects” selects
      `writing-manuscript-audit`.
- [ ] A grammar, translation, local rewrite, or naturalness-only request does not
      load a section-structure reference.

## Progressive loading

- [ ] Abstract work loads only `references/abstract-structure.md`.
- [ ] Introduction work loads only `references/introduction-structure.md`.
- [ ] Method work loads only `references/method-structure.md`.
- [ ] Other sections use the base workflow unless another explicit resource applies.

## Output and preservation

- [ ] `outline` returns a story map and paragraph plan rather than forced prose.
- [ ] A prose operation returns revised text first.
- [ ] Each planned paragraph has one dominant function.
- [ ] Claims, numbers, formulas, citations, uncertainty, and protected spans are
      preserved.
- [ ] Unsupported comparative or priority claims are weakened or marked.

## Instruction hygiene

- [ ] `SKILL.md` owns routing and workflow.
- [ ] References contain section-specific reasoning, not repeated global policy.
- [ ] The template defines the reusable artifact without prescribing a fixed story.
- [ ] No active instruction is duplicated verbatim across the new resources.
