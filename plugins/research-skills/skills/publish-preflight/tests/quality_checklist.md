# Publish Preflight Quality Checklist

- [ ] All four Registry modes appear.
- [ ] Venue/channel, cycle, track, phase, portal, and final candidate identity are explicit.
- [ ] Current rules use official sources and record effective/retrieval dates.
- [ ] Every required artifact is present or explicitly missing.
- [ ] Rules, artifacts, checks, and findings use stable IDs and mappings.
- [ ] Findings include exact location/evidence, consequence, action, owner, and recheck.
- [ ] Ready requires all hard rules/material checked and no Blocker/Major/unresolved gap.
- [ ] Ready cannot pass with empty rule/artifact/check ledgers or unresolved scope.
- [ ] Conditionally ready has no Blocker or unchecked hard rule/material; any remaining
      condition is a bounded non-hard confirmation or final portal identity check.
- [ ] A rebuilt local file is not assumed identical to the portal candidate.
- [ ] The machine-readable manifest has valid RULE/ART/CHK/FIND mappings, contained
      paths, and an evidence-backed verdict.
- [ ] Sensitive authorship/license/ethics/release changes require confirmation.
- [ ] No upload, portal mutation, scientific acceptance claim, or fabricated rule occurs.
