# Tool Zotero PDF Ingestion Quality Checklist

- [ ] All five Registry modes appear.
- [ ] Zotero metadata and PDF source set satisfy the minimum contract.
- [ ] Items, attachments, and physical PDFs have separate identities.
- [ ] Hash/stable-ID evidence is separate from fuzzy title/author/path similarity.
- [ ] Contradictory stable fields force conflict/review.
- [ ] One-to-many, version, supplementary, and duplicate relations are preserved.
- [ ] Fuzzy candidates and ties are not auto-matched.
- [ ] Manifest validator self-test and target validation pass before export.
- [ ] KB-ready and unresolved queues are separate.
- [ ] No Zotero/PDF mutation or unapproved local export occurs.
