# Visual Expression Mining Quality Checklist

- [ ] All five Registry modes appear.
- [ ] Sources and target visual use satisfy the minimum input.
- [ ] `VIS-*` observations include exact source location and quality.
- [ ] Visible structure, inferred function, and protected content are separate.
- [ ] `PAT-*` covers role, topology, encoding, annotation, order, prerequisites, and risk.
- [ ] Source-local observations are not generalized without comparison.
- [ ] Assessment dimensions remain independent and include counterexamples/boundaries.
- [ ] Reuse status is conservative and rights uncertainty is explicit.
- [ ] Presentation handoff does not choose final deck style.
- [ ] No final figure/table/plot is generated or copied.
