# Writing Knowledge Capture Quality Checklist

- [ ] All ten Registry modes appear.
- [ ] Source material/instruction and intended use are present.
- [ ] Content is reusable and copyrighted source text is abstracted.
- [ ] Provenance, context, intended use, avoid-when, and confidence are present.
- [ ] Deduplication scope and exact/near/semantic/unknown class are recorded.
- [ ] New records are validated and staged only as `pending_review`.
- [ ] Staging uses `knowledge/academic-writing/inbox/`.
- [ ] Approval/rejection is explicit and entry-specific with audit metadata.
- [ ] Entry identity/provenance and prior state remain traceable.
- [ ] No direct KnowledgeHub, Zotero, or index write occurs.
