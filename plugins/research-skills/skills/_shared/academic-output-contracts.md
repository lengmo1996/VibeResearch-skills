# Academic Output Contracts

Every output must state its material scope, distinguish source claims from inference, preserve user data/formulas, and list unresolved evidence. Use concise tables only when they improve traceability.

Composed tasks pass a handoff containing: primary Skill, modes used, materials read, retrieval state, search budget used, evidence ledger IDs, terminology/symbol decisions, unresolved items, and the next Skill. Do not repeat reading or retrieval already completed upstream.

Default task limit: one primary Skill and at most two supporting Skills. Never auto-loop between Skills.
