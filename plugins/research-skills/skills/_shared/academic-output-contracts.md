# Academic Output Contracts

Every output distinguishes source claims from inference and preserves user data and
formulas. State the material scope when it is partial (abstract only, cropped figure,
one section) and that limits the conclusion. Name unresolved evidence when a specific
gap would change the reader's decision, with the reason; do not append a generic
limitations list. Use concise tables only when they improve traceability. How results
read is governed by [output voice](output-voice.md).

Actual cross-Skill handoffs carry only relevant scope, evidence, unresolved items,
and authorization, reusing existing IDs and context. Omit unused retrieval, budget,
or ledger fields. Do not create a handoff for a standalone answer or repeat upstream
reading and retrieval.

For matching tasks, use one primary Skill and at most two supporting Skills. Handle
unmatched tasks directly. Never auto-loop between Skills.
