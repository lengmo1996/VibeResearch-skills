# Presentation Visual QA

For audit-only work, record the supplied plan/deck and selected checks, then inspect
only applicable items. Mark unavailable views or evidence `not checked`; do not build
a new narrative or rank visual candidates to complete this checklist. Add a rule guide
only for the check being performed.

## Narrative and evidence

- [ ] Every slide has one stable ID, supported claim or navigation purpose, and source trace.
- [ ] Total slide timing leaves the declared discussion reserve.
- [ ] Missing data or visuals remain blocked rather than fabricated.
- [ ] A visual-plan pass is not reported as an artifact or content-fidelity pass.

## System consistency

- [ ] One selected visual system governs color, type, spacing, chart, and motion.
- [ ] Every slide uses a documented layout or an explained exception.
- [ ] Titles state claims or navigation purpose.

## Projection and export

- [ ] 16:9 or requested canvas renders without clipping.
- [ ] Body text is at least 18 pt; primary titles are at least 28 pt.
- [ ] Safe margins are at least 0.35 in.
- [ ] PPTX, PDF, and thumbnail previews preserve hierarchy and meaning.
- [ ] Only formats that were actually rendered or exported are marked checked.

## Evidence and charts

- [ ] Axes, units, baselines, uncertainty, and source trace are present when applicable.
- [ ] Color is not the only carrier of meaning.
- [ ] Tables retain only comparisons needed for the slide claim.

## Interaction and motion

- [ ] Links and navigation have a non-interactive fallback.
- [ ] Reveals preserve meaning when exported as a static slide.
- [ ] Motion is purposeful, brief, and safe for reduced-motion needs.

## Accessibility

- [ ] Text/background contrast is at least 4.5:1 for normal text.
- [ ] Visuals have alt text or an equivalent description in notes.
- [ ] Reading order, captions, and speaker-note descriptions are coherent.
