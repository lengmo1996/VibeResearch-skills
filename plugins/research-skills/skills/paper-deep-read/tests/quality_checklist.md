# Paper Deep Read Quality Checklist

- [ ] Exactly one allowed primary input type is identified.
- [ ] The narrowest applicable mode is used.
- [ ] All modes reuse one evidence ledger.
- [ ] Material claims have stable `CLM-*` IDs across mode changes.
- [ ] Paper statements, supported interpretations, and unconfirmed inferences are separate.
- [ ] Equations preserve symbols and identify dimension/derivation boundaries.
- [ ] Figure arrows/modules are tied to visible evidence.
- [ ] Table metrics, direction, and comparison protocol are explicit.
- [ ] Cropped, blurred, unreadable, or legend-free visuals lower confidence.
- [ ] Partial material is not presented as a full-paper conclusion.
- [ ] Cross-mode conflicts are recorded rather than silently overwritten.
- [ ] Runtime instructions do not load unlinked `legacy-assets/`.
- [ ] No code, execution, test, or migration work is performed.
