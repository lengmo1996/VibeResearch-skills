# Literature Synthesis Quality Checklist

- [ ] Scope, paper-set source, inclusion/exclusion, and coverage target are explicit.
- [ ] All Registry modes and required-RAG default remain clear.
- [ ] Narrow modes use only their required output sections and reference fragments; compare remains an alias of comparison.
- [ ] Papers, claims, and any axes or gaps actually used have stable IDs.
- [ ] Any comparison axes state evidence and non-comparability conditions.
- [ ] Result comparisons stay within compatible protocol groups.
- [ ] Each produced taxonomy, consensus, disagreement, or gap cites evidence claim IDs.
- [ ] Any gap entries include counter-evidence and falsification conditions; no supported gaps is a valid result.
- [ ] Zero hits and empty cells are not described as research gaps.
- [ ] Search summaries describe actual retrieval; saturation is based on observed evidence change and bounded scope.
- [ ] Evidence-map and related-work use the shared map as their ledger without a duplicate table.
- [ ] No unlinked legacy asset or unsupported final prose is used.
