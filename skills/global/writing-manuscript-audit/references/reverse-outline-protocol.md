# Reverse-outline protocol

Load this reference only for `structure` mode. Analyze the supplied manuscript or
section as written; do not design a replacement outline.

## 1. Inventory paragraph functions

For each paragraph or stable block, record:

- exact locator;
- dominant function, such as context, gap, claim, rationale, method step, evidence,
  interpretation, limitation, or transition;
- principal claim or question;
- evidence supplied or referenced;
- dependency on earlier content;
- transition promised to the next block.

Use one dominant function even when a paragraph has secondary roles. Mark an
uncertain function as an inference instead of forcing a label.

## 2. Build the dependency view

Trace:

- which evidence supports each material claim;
- which definitions or assumptions a later step requires;
- whether contribution statements reappear consistently in method, experiments, and
  conclusion;
- whether a transition closes the current function and establishes the next one.

An absent link is unresolved when the necessary section or supplement is outside the
supplied scope.

## 3. Diagnose structural defects

Only create a finding when the observed map supports it:

- **duplicate role:** adjacent blocks repeat the same argumentative job;
- **orphan claim:** a material claim lacks visible evidence or a promised verifier;
- **orphan evidence:** a result appears without a claim or question it resolves;
- **argument jump:** a conclusion depends on an unstated premise or definition;
- **premature detail:** implementation detail appears before the reader has its role;
- **section leakage:** content performs a function owned by another section and
  disrupts the current progression;
- **contribution drift:** contribution wording or scope changes across sections;
- **weak transition:** adjacency is present, but the dependency is not explained.

Do not label stylistic preference as a structural defect. Merge repeated symptoms
only when one root cause and correction covers them.

## 4. Prepare the handoff

For each accepted finding, provide:

- affected locators and map rows;
- observed dependency failure;
- smallest structural correction, such as move, merge, split, define, qualify, or add
  a transition;
- scientific content that must remain protected;
- verification criterion for a later `$writing-academic` revision.

The handoff describes constraints and accepted findings. It does not draft replacement
prose unless the user separately invokes the writing Skill.
