# Quality Checklist

- Workload, environment, concurrency, and hard/soft requirements are explicit.
- Observations retain evidence class, scope, timestamp, source, and units.
- Effective process/container/scheduler constraints outrank host visibility.
- Unknown is neither zero nor unlimited.
- Accelerator visibility is not reported as runtime usability.
- Every requirement has one evidence-linked match.
- CPU threading, memory headroom, disk stages, wall time, and cost are considered.
- Fallbacks are bounded and do not execute.
- Host, job, device, path, environment, and credential identifiers are redacted.
- Verdict matches hard requirement states.
