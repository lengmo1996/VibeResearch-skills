# Quality checklist

- [ ] Frontmatter starts with the triggering scenario, names the output, and excludes
  adjacent paper, literature, and code tasks.
- [ ] Both Registry modes are present and RAG is optional overall.
- [ ] The minimum input is only a concept or technical topic.
- [ ] Ambiguity is resolved or explicitly preserved.
- [ ] The explanation follows a prerequisite-to-mechanism dependency ladder.
- [ ] Claims distinguish fact, source-local definition, interpretation, and unknown.
- [ ] Current and local-document claims include date or document identity.
- [ ] Contrasts use a consistent decision-relevant axis.
- [ ] Reading recommendations include purpose and prerequisite.
- [ ] No citation, consensus, priority, page, or document identity is fabricated.
