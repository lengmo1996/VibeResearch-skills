# Paper Triage Quality Checklist

- [ ] All four Registry modes use canonical names.
- [ ] Each candidate has title plus abstract, full text, or useful metadata, or is
  labeled `insufficient-material`.
- [ ] Visible facts, abstract claims, inference, and missing information are separate.
- [ ] Priority and confidence are independent and rubric-calibrated.
- [ ] Every candidate has exactly one primary next action.
- [ ] Batch/watch results rank every supplied candidate and declare tie-break rules.
- [ ] P0 is scarce and tied to an immediate decision.
- [ ] No method, experiment, novelty, code-quality, or reproducibility detail is invented.
- [ ] No deep reading, active discovery, synthesis, or persistence occurs.
