# Idea Generation Quality Checklist

## Required behavior

- [ ] Uses only research goal/problem context as required input.
- [ ] Selects a registered generation mode.
- [ ] Generates mechanism-distinct candidates before ranking.
- [ ] Separates verified facts, evidence-backed gaps, assumptions, and speculation.
- [ ] Gives every idea a counter-hypothesis, falsifier, minimum validation, and kill criterion.
- [ ] Assesses feasibility from supplied resources.
- [ ] Does not claim novelty from retrieval absence.
- [ ] Ranks with independent axes and visible tradeoffs.
- [ ] Does not expand into full experiment design or implementation.
