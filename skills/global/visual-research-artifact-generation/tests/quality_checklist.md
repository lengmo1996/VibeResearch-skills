# Visual Research Artifact Generation Quality Checklist

- [ ] All six Registry modes appear and exactly one primary backend is selected by default.
- [ ] Visual goal/input and intended use satisfy the minimum contract.
- [ ] Supplied facts/data/relations use `SRC-*` and output elements use `ELEM-*`.
- [ ] The artifact has a stable `FIG-*`, optional `PAN-*`, one primary narrative
      role, and preserved upstream `CLM-*` IDs.
- [ ] Every meaningful element maps to source evidence or explicit inference.
- [ ] Claim coverage and cross-figure relationships are explicit and independently
      validated.
- [ ] Editable source is separate from content/data and rendering logic.
- [ ] Revisions account for preserved, changed, added, and removed elements.
- [ ] Structure, compile, render, visual, and semantic validation statuses are independent.
- [ ] Preview/render claims correspond to an actual inspected output.
- [ ] Missing values, hidden content, labels, units, or statistics are not fabricated.
- [ ] RAG remains never and outputs stay within authorized workspace paths.
