# Academic Output Contracts

Every output must state its material scope, distinguish source claims from inference, preserve user data/formulas, and list unresolved evidence. Use concise tables only when they improve traceability.

Actual cross-Skill handoffs carry only relevant scope, evidence, unresolved items,
and authorization, reusing existing IDs and context. Omit unused retrieval, budget,
or ledger fields. Do not create a handoff for a standalone answer or repeat upstream
reading and retrieval.

For matching tasks, use one primary Skill and at most two supporting Skills. Handle
unmatched tasks directly. Never auto-loop between Skills.
